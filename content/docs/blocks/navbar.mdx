## Installation

Copy the files above into your app, then add the components they use:

```npm
npx shadcn@latest add button collapsible kbd command
```

The theme toggle needs [`next-themes`](https://github.com/pacocoursey/next-themes). Search is optional: pass `onSearch` to show the search button and bind <kbd>⌘</kbd> <kbd>K</kbd>.
