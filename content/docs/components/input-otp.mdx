## Installation

```npm
npx shadcn@latest add input-otp
```

## Usage

```tsx
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSlot,
} from "@/components/ui/input-otp"
```

```tsx
<InputOTP maxLength={6}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
</InputOTP>
```

## Guidelines

- Match `maxLength` to the number of slots you render.
- Restrict characters with `pattern` when the code is numeric.
- Group long codes with `InputOTPSeparator` so they're easier to read and type.
