## Installation

```npm
npx shadcn@latest add input
```

## Usage

```tsx
import { Input } from "@/components/ui/input"
```

```tsx
<Input type="email" placeholder="Email" />
```

## Guidelines

- Always provide a visible label. Placeholders aren't labels.
- Use the right `type` and `inputMode` so mobile keyboards match the content.
- Explain errors in text next to the field, not with color alone.
