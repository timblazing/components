## Installation

```npm
npx shadcn@latest add progress
```

## Usage

```tsx
import { Progress, ProgressLabel, ProgressValue } from "@/components/ui/progress"
```

```tsx
<Progress value={66} />
```

## Guidelines

- Use progress only when you can measure completion; otherwise use a [Spinner](/components/spinner).
- Pair with a label so the value has context.
- Keep the bar monochrome.

## API

See the shadcn/ui [Progress](https://ui.shadcn.com/docs/components/base/progress) docs and Base UI [Progress](https://base-ui.com/react/components/progress).
