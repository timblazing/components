## Guidelines

- Use one `default` button per view for the primary action. Everything else is `outline`, `secondary`, or `ghost`.
- Use `destructive` only for actions that delete or can't be undone, and confirm them with an [Alert Dialog](/components/alert-dialog).
- Give icon-only buttons an `aria-label`.
