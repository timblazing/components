## Guidelines

- Use a switch when the change takes effect immediately. Use a [Checkbox](/components/checkbox) when the user must submit.
- Label the setting, not the action. Write "Airplane mode", not "Turn on airplane mode".
- Always associate a label with `htmlFor` and `id`.
