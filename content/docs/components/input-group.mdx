## Installation

```npm
npx shadcn@latest add input-group
```

## Usage

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
} from "@/components/ui/input-group"
```

```tsx
<InputGroup>
  <InputGroupInput placeholder="Search..." />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

## Guidelines

- Use `InputGroup` instead of positioning icons by hand. It handles focus rings and padding.
- Keep addons short. Long help text belongs in a `FieldDescription`.
- Give inline buttons an `aria-label` when they only show an icon.
