## Installation

```npm
npx shadcn@latest add collapsible
```

## Usage

```tsx
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@/components/ui/collapsible"
```

```tsx
<Collapsible>
  <CollapsibleTrigger>Can I use this in my project?</CollapsibleTrigger>
  <CollapsibleContent>
    Yes. Free to use for personal and commercial projects.
  </CollapsibleContent>
</Collapsible>
```

## Guidelines

- Use a collapsible for one optional section. For a group of related sections, use an [Accordion](/components/accordion).
- Keep the trigger always visible and indicate state with a rotating chevron.
- Control `open` only when other UI depends on it; otherwise rely on `defaultOpen`.
