## Installation

```npm
npx shadcn@latest add toggle
```

## Usage

```tsx
import { Toggle } from "@/components/ui/toggle"
```

```tsx
<Toggle aria-label="Toggle bold" variant="outline">
  <BoldIcon />
</Toggle>
```

## Guidelines

- Use a toggle for a state that persists, like bold or mute. Use a [Button](/components/button) for one-off actions.
- Give icon-only toggles an `aria-label`.
- Prefer the `outline` variant when the toggle sits alone on a surface.
