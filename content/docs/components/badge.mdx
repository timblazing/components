```npm
npx shadcn@latest add badge
```

## Usage

```tsx

```

```tsx
<Badge variant="secondary">Badge</Badge>
```

## Guidelines

- Keep badges to one or two words.
- Use color only to convey status (`success`, `warning`, `info`, `destructive`). Everything else is `default`, `secondary`, or `outline`.
- Don't use a badge as a button; use a [Button](/components/button) for actions.
