## Installation

```npm
npx shadcn@latest add hover-card
```

## Usage

```tsx
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,
} from "@/components/ui/hover-card"
```

```tsx
<HoverCard>
  <HoverCardTrigger render={<a href="/user" />}>@nextjs</HoverCardTrigger>
  <HoverCardContent>The React framework for production.</HoverCardContent>
</HoverCard>
```

## Guidelines

- Use for sighted-mouse previews of a link's destination; the trigger must remain useful on its own.
- Never put essential information or actions only in the card; touch and keyboard users may not see it.
- Keep it to a glanceable summary.
