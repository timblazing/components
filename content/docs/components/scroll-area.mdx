## Installation

```npm
npx shadcn@latest add scroll-area
```

## Usage

```tsx
import { ScrollArea } from "@/components/ui/scroll-area"
```

```tsx
<ScrollArea className="h-72 w-48 rounded-md border">
  {/* long content */}
</ScrollArea>
```

## Examples

### Horizontal

Add a `ScrollBar` with `orientation="horizontal"` and make the content `w-max`.

<ComponentPreview name="scroll-area-horizontal" />

## Guidelines

- Give the scroll area an explicit height (or width for horizontal) so it has something to overflow.
- Prefer native scrolling for the page itself; use this for contained regions like lists and panels.
- Make sure scrollable regions remain reachable by keyboard.
