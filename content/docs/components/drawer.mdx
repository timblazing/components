## Installation

```npm
npx shadcn@latest add drawer
```

## Usage

```tsx
import {
  Drawer,
  DrawerContent,
  DrawerDescription,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@/components/ui/drawer"
```

```tsx
<Drawer showSwipeHandle>
  <DrawerTrigger render={<Button variant="outline" />}>Open</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Set a goal</DrawerTitle>
      <DrawerDescription>Choose your daily target.</DrawerDescription>
    </DrawerHeader>
  </DrawerContent>
</Drawer>
```

## Guidelines

- Prefer a drawer on touch devices where swiping to dismiss feels natural; use a [Dialog](/components/dialog) on desktop.
- Constrain content width inside `DrawerContent` so it doesn't stretch on wide screens.
- Always provide a visible close action, not just the swipe gesture.
