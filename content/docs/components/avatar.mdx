## Installation

```npm
npx shadcn@latest add avatar
```

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
```

```tsx
<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
  <AvatarFallback>CN</AvatarFallback>
</Avatar>
```

## Guidelines

- Always render an `AvatarFallback` with initials; images fail.
- Keep avatars monochrome and circular. Use `AvatarBadge` color only for presence status.
- Don't use an avatar as the only identifier in a list; pair it with a name.
