## Installation

```npm
npx shadcn@latest add carousel
```

## Usage

```tsx
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselNext,
  CarouselPrevious,
} from "@/components/ui/carousel"
```

```tsx
<Carousel>
  <CarouselContent>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
  </CarouselContent>
  <CarouselPrevious />
  <CarouselNext />
</Carousel>
```

## Guidelines

- Keep slide counts small and content scannable.
- Don't hide critical information in later slides.
- The previous and next buttons sit outside the carousel; leave room for them.

## API

See the shadcn/ui [Carousel](https://ui.shadcn.com/docs/components/base/carousel) docs and [Embla Carousel](https://www.embla-carousel.com/api/).
