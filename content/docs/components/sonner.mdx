## Installation

```npm
npx shadcn@latest add sonner
```

## Usage

```tsx
import { toast } from "sonner"
```

```tsx
toast("Event has been created")
```

## Guidelines

- Use toasts for confirmation of something that already happened, not for errors that need action.
- Keep messages under one line when possible.
- Always offer undo for destructive actions instead of a confirmation toast alone.
