## Installation

```npm
npx shadcn@latest add tooltip
```

## Usage

```tsx
import {
  Tooltip,
  TooltipContent,
  TooltipProvider,
  TooltipTrigger,
} from "@/components/ui/tooltip"
```

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger render={<Button variant="outline" />}>Hover</TooltipTrigger>
    <TooltipContent>Add to library</TooltipContent>
  </Tooltip>
</TooltipProvider>
```

## Guidelines

- Keep text to a few words and never put interactive content inside.
- Wrap related tooltips in one `TooltipProvider` so subsequent tooltips open instantly.
- Don't rely on a tooltip for critical information; it isn't available on touch devices.
