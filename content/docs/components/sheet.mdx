## Installation

```npm
npx shadcn@latest add sheet
```

## Usage

```tsx
import {
  Sheet,
  SheetContent,
  SheetDescription,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@/components/ui/sheet"
```

```tsx
<Sheet>
  <SheetTrigger render={<Button variant="outline" />}>Open</SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Edit profile</SheetTitle>
      <SheetDescription>Make changes to your profile.</SheetDescription>
    </SheetHeader>
  </SheetContent>
</Sheet>
```

Sheet is built on the Base UI Dialog.

## Examples

## Guidelines

- Use for secondary tasks that keep the user in context, such as editing a record or filtering a list.
- Default to `right`; use `left` for navigation and `bottom` on mobile.
- Keep the primary action in `SheetFooter`.
