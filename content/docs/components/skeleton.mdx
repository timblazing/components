## Installation

```npm
npx shadcn@latest add skeleton
```

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton"
```

```tsx
<Skeleton className="h-4 w-[250px]" />
```

## Guidelines

- Match the layout of the loaded content to prevent shifts.
- Use skeletons for content areas and a [Spinner](/components/spinner) for actions.
- Don't show a skeleton for more than a few seconds without a fallback.
