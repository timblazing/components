## Installation

```npm
npx shadcn@latest add popover
```

## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from "@/components/ui/popover"
```

```tsx
<Popover>
  <PopoverTrigger render={<Button variant="outline" />}>Open</PopoverTrigger>
  <PopoverContent>
    <PopoverHeader>
      <PopoverTitle>Title</PopoverTitle>
      <PopoverDescription>Description</PopoverDescription>
    </PopoverHeader>
  </PopoverContent>
</Popover>
```

## Guidelines

- Use for small, interactive content such as a form or settings; it opens on click.
- Use a [Tooltip](/components/tooltip) for plain text hints and a [Hover Card](/components/hover-card) for previews.
- Keep content brief; move anything long into a [Dialog](/components/dialog) or [Sheet](/components/sheet).
