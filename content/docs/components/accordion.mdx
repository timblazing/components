## Installation

```npm
npx shadcn@latest add accordion
```

## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion"
```

```tsx
<Accordion defaultValue={["item-1"]}>
  <AccordionItem value="item-1">
    <AccordionTrigger>Is it accessible?</AccordionTrigger>
    <AccordionContent>Yes. It follows the WAI-ARIA pattern.</AccordionContent>
  </AccordionItem>
</Accordion>
```

`value` and `defaultValue` are always arrays of item values.

## Guidelines

- Use an accordion for scannable content like FAQs, not for steps the user must complete in order.
- Write short, descriptive trigger labels so users can decide what to open without expanding everything.
- Don't hide critical information, such as errors or required fields, inside a collapsed item.
