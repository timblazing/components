## Installation

```npm
npx shadcn@latest add slider
```

## Usage

```tsx
import { Slider } from "@/components/ui/slider"
```

```tsx
<Slider defaultValue={[50]} max={100} step={1} />
```

## Guidelines

- Show the current value nearby. A thumb position alone isn't precise.
- Choose a `step` that matches the precision users need.
- Provide an `aria-label` when there is no visible label.
