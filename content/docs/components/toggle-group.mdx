## Installation

```npm
npx shadcn@latest add toggle-group
```

## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group"
```

```tsx
<ToggleGroup spacing={0} variant="outline" multiple>
  <ToggleGroupItem value="bold" aria-label="Toggle bold">
    <BoldIcon />
  </ToggleGroupItem>
  <ToggleGroupItem value="italic" aria-label="Toggle italic">
    <ItalicIcon />
  </ToggleGroupItem>
</ToggleGroup>
```

## Guidelines

- Use `multiple` for independent formatting options and a single-select group for mutually exclusive views.
- Keep groups short, ideally five items or fewer.
- Give icon-only items an `aria-label`.
