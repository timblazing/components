## Installation

```npm
npx shadcn@latest add native-select
```

## Usage

```tsx
import { NativeSelect, NativeSelectOption } from "@/components/ui/native-select"
```

```tsx
<NativeSelect>
  <NativeSelectOption value="todo">Todo</NativeSelectOption>
  <NativeSelectOption value="done">Done</NativeSelectOption>
</NativeSelect>
```

## Guidelines

- Prefer Native Select on mobile and in simple forms. The OS provides the picker.
- Use [Select](/components/select) when you need custom option content or styling.
- Add a disabled placeholder option when there's no sensible default.
