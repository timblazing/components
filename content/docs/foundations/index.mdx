## Principles

- **Tokens, not values.** Use semantic tokens (`bg-card`, `text-muted-foreground`, `border-border`) so both themes work without overrides.
- **Color means something.** The palette is neutral. Color is reserved for status — success, warning, error, information — and for data.
- **Hairlines over shadows.** Separate layers with 1px borders and a step in surface color. Shadows are for things that float: menus, popovers, dialogs.
- **Compose, don't fork.** Build from the components in `components/ui`. If something is missing, compose it from what exists before writing a new primitive.
- **Light and dark are equals.** Both follow the system preference and get the same care.
