## Families

<FontFamilies />

All three families are bundled by the `geist` package and self-hosted with `next/font/local`. Geist Sans powers UI, body text, and component headings through `--font-sans` and `--font-heading`. Geist Mono powers code, tokens, and chart annotations through `--font-mono`. Geist Serif uses the regular round-dot variant for page titles and hero text through `--font-serif`, also aliased as `--font-display`. Every page, including standalone block previews, inherits these fonts from the root layout.

## Usage

```tsx
<h1 className="font-display text-4xl tracking-[-0.04em]">Foundations</h1>
<p className="text-base leading-7 text-muted-foreground">Supporting copy.</p>
<code className="font-mono text-[13px] tabular-nums">96.8%</code>
```

- Do keep display type at its native weight 400 with tight tracking.
- Do use `tabular-nums` anywhere numbers line up: tables, stats, charts.
- Don't use the display face below 30px or for UI labels.
- Don't use more than two weights in one view.
